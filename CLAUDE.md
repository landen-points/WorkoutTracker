# Pixel Workout Tracker Stack
- Language: Kotlin
- UI Framework: Jetpack Compose (no XML)
- Database: Room Database with Coroutines/Flow
- Architecture: MVVM (Model-View-ViewModel)

# Rules
- Use local SQLite database via Room to persist workouts.
- Keep UI composables clean and stateless where possible.
- Use Android Material 3 design system optimized for Pixel screens.
